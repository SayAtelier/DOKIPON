# UX デザイン仕様

- 配色：背景 `#0B1220`、表面 `#121D2E`、選択 `#5AC7C3`、失敗 `#F08886`。色以外にラベル・線のスタイルで状態を判別できるようにする。
- 要素構成：共通ヘッダー、探索サイドバー、主表示領域、文脈別インスペクター、4D/5D 専用タイムライン。
- 観測対象が特定できないときに、装飾目的のノードや架空の実測値を生成しない。
- 3D では Floor / Room と Graph ID の意味を分離する。関連しないノードの退避は描画上のみに適用する。
- 専門図は独立した詳細ダイアログで確認できる。意味的に未確定な ER 属性は Designed と明示する。
- ブラウザーが WebGL を提供しない場合は Canvas2D 投影に切り替え、GPU 実行と誤認させない。
- 日本語の長い文章、キーボード操作、狭幅画面、Reduced Motion、スクリーンリーダー用の代替説明を品質観点に含める。すべての WCAG 2.2 AA 項目の正式監査合格は未確認とする。

## Node/Edge セマンティックラベル（適用済みの設計契約）

- Node、Edge ともに意味が分かる正式名称を持ち、同じ ID に紐付ける。Edge はアクション・関係名とソース／ターゲットを表示する。
- 3D オブジェクトとラベルの位置を分離する。ワールド座標を毎フレーム投影してスクリーン座標上に横書き表示し、Yaw／Pitch／Zoom／View 変化でも文字が反転しない。
- 初期設定は自動衝突回避。全件表示、関連のみ表示へ切替可能とし、重要度の高い選択対象とイベント関連を優先する。省略や非表示時も Tooltip とインスペクターに正式名称を保持する。
- フォーカス移動およびイベント再生では、正式 ID と描画位置を常時整合させる。5D 介入による新規ノードと分割 Edge は、ベースラインと区別可能なラベルと ID を持つ。
- Building／Floor は意味的な表示グループであり、実装済みソースの Node と誤解させない。
- 画面サイズ 390px に対応し、ラベル文字列は背景／図形に対して読みやすいコントラストを維持する。全角長文や全方位の GPU オクルージョンに対する完全試験は未実施。
