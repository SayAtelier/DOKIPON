选中某个状态后，下方按钮可驱动自动轮询（模拟 CheckoutController.poll()）：状态只会前进，不会回退， 且任何情况下都不会重新提交结算。

客户端的三条铁律（storefront_state/checkout_controller.dart）

  • 一次逻辑尝试只提交一次；HTTP 层的重试复用同一 Idempotency-Key，所以传输层重试在服务端也是重放。
  • 轮询预算耗尽不谎报失败：client.poll_budget_exhausted 提示去查订单，明确说明「没有被重复扣款」。
  • 幂等冲突 = 需要新的操作：同 key 不同 payload 时 409，此时必须换新 key 并重新读取，不能盲目重试。
