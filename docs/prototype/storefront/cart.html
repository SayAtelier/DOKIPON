楽観的並行制御 / Optimistic concurrency

カートの更新は「変更の根拠にした version」を送ります。409 は上書きではなく 再読込して再適用。プレースホルダの version を故意に古くして衝突を再現できます。

购物车的四条硬规则

  • 客户端小计只是快照 — CartLine.unitAmountSnapshot 是「显示用」；改它只改变用户看到的数字，不改变被收取的金额（服务端在结算时重算）。
  • 每次变更都带 version — expected_version；不一致返回 409 cart.version_conflict，客户端应重新拉取后重放，不是覆盖。
  • 购物车会过期 — expires_at_ms。
  • 货币不可混算 — Money 的加法在跨币种时抛错，而不是静默换算。
