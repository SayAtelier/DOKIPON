      Order 的结构（commerce-order/src/main.rs L58-L88）

      字段含义
      state结算状态机的当前态
      lines[]订单行。单价是结算时刻的服务端权威单价
      total金额（整数最小单位 + 币种）
      reservation_id库存预留凭证
      provider_ref支付服务商侧凭证
      transitions_used已用状态跃迁次数
      trail[]事件轨迹（sequence / event / from_state / to_state）
      outbox[]待投递的领域事件
      awaiting_reconciliation是否等待与支付服务商对账

      为什么 trail 重要

      出现「到底扣没扣款」时，可回答的唯一事实来源是这条轨迹 + 服务商凭证， 而不是客户端的本地状态。5D 因果层（对账 / 反事实）就建在它上面。
