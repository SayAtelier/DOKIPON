忠实に再現した挙動

  • チャネルで商品が変わる — チャネル非対応商品はサーバが返さない（channel_eligibility）。左の Web / App / LINE を切り替えて確認。
  • カーソルページング — 実クライアントは limit=20 固定（本プロトタイプでは説明用に 6 件/页）、next_cursor があれば「もっと見る」。
  • ページ取得失敗で既存リストを消さない — CatalogController.load() は失敗時も _items を保持。
  • 在庫切れは購入不可 — ProductCard は out-of-stock だと「追加」ボタンを出さず「不可 / N/A」を出す。
  • チャネルヘッダは常に送信 — チャネルを外さない。
