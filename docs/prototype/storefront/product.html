価格バージョン / Price version

この画面が指すもの

GET /v1/products/{productId} x-channel: web | app | line

ProductDetail が持つ情報

フィールド意味
productId商品 ID
skuSKU（在庫・価格はこの単位）
price権威価格。Money（整数最小単位 + ISO-4217）
versionサーバ側価格版。古い版をカートに持ったまま決済すると再評価される
stockPolicyunbounded / reserved / made_to_order。reserved のみが在庫 Saga に参加
availability在庫表示（在庫あり / 残りわずか / 在庫切れ / 受注生産）
channelEligibilityチャネル別販売可否。LINE は他チャネルより厳格
titleI18n多言語タイトル。フォールバックは request → ja → 最初の要素

操作

  • バージョンを進める — 価格改定を再現。カートに古い版が入っていると、決済時に再評価される。
  • チャネル切替 — 非対応チャネルでは販売不可。
  • 在庫切れ — 追加ボタンが無効化される（ProductCard と同じ扱い）。

注意（実装現状）

サーバの commerce-catalog は product_id / amount_minor / stock_policy / channel_eligibility を snake_case で返すが、 Dart クライアントの ProductDetail.fromJson は productId / stockPolicy / channelEligibility（camelCase のみ）を読む。 差分は suite 索引の「真实实现现状」表に全件掲載。
