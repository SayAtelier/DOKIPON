        application/problem+json
        {type,title,status,code,detail,traceId,retryable}
      
    

      
    五个判定子（problem.dart L28-L49）
    
      
    
        
    判定子条件客户端该做什么
    
        
    
          isUnresolvedPayment
          code 以 payment.unknown / checkout.pending 开头
          改轮询，绝不重提结算
        
    
        
    
          isVersionConflict
          code == cart.version_conflict
          重新拉取购物车后重放变更
        
    
        
    
          isIdempotencyConflict
          code 含 idempotency
          换新 Idempotency-Key 并重新读取
        
    
        
    
          isLineUnavailable
          code 以 line. 开头
          降级提示，商店其余部分照常
        
    
        
    
          requiresLogin / isForbidden
          status 401 / 403
          提示登录 / 提示无权
        
    
      
    

      
    两条不能违反的约束
    
      
      
        
    • retryable=false 不得触发重试循环。
      • 
        
    • payable 未知 ≠ 失败：payment.unknown 时文案不能说「支付失败」，更不能引导用户再付一次。
