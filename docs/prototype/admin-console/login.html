运营后台登录

电商交易系统的运营账号登录入口。接口契约不变—— POST /gm/login · 请求体 {username, password} · 成功返回 {token}，前端存入 localStorage["gm.authToken"]。

原型不校验密码：任意非空用户名 + 任意密码均可登录。留空任一字段即可复现真实构建的 invalid_credentials 错误分支。
