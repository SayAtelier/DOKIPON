营销素材下发

向 App / Web / LINE 客户端推送营销素材（透明叠加图层）。 对应 POST /gm/canvas/send；锚点清单来自 GET /gm/canvas/anchors。

命名与设计文档不一致 本页不是RGS-REQ-024 / RGS-BAS-021 定义的「GM后台拓扑可视化无限画布」。 代码实现的是向 App / Web / LINE 客户端推送透明叠加图层（默认层名 gm_overlay）， 仓库中没有任何拓扑渲染代码。导航名沿用端点族命名，见索引页走查问题 #2。
提供以 Base64 编码的原始 RGBA 像素。上传图片会在客户端自动转换为 RGBA。
支持的格式会在上传时转换为原始 RGBA。Supported formats are converted to raw RGBA on upload.
Pixels — RGBA bytes — Base64 length 0
