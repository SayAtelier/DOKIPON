金额口径

price 以 JSON number 传输，真实构建用 toFixed(2) 展示； 本原型按电商口径改为整数元显示（¥128 / ¥1,026）。 仓库 README.md 的 Working agreements 规定「Money 是整数最小货币单位 + ISO-4217， 业务金额不得用 double」——字段类型仍与该约定不一致（索引页走查问题 #5 依然成立），本次只改界面口径，不动后端字段。
另：契约中的 MallItem{id,name,price} 没有库存字段， 因此本页不展示在售状态（在庫あり / In stock、在庫切れ / Out of stock）； 若要展示，需后端先补 stock 枚举。
