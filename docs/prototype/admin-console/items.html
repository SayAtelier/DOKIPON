补偿与兑换码发放

向指定消费者发放补偿权益与兑换码，并保留完整操作审计记录。 对应 POST /gm/items/grant，请求体 {player_id, item_id, amount}。

走查提示 真实构建中「Grant Item」是单击直发，无二次确认（Items.tsx:150）。 补偿发放属于不可逆的权益操作，原型补了确认框并回显发放量，差异见索引页走查问题 #4。
