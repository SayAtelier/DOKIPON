## 性能テスト条件
- Desktop: Chromium Stable / 16GB RAM 相当。
- Mobile: iOS WKWebView、Android WebView と外部ブラウザを別々に評価。
- LINE: 認証/匿名/外部ブラウザで LIFF API 適用可否をケース分離。
- 大規模図: ノード数 50/500/5000、エッジ数 100/1000/10000 をスケール別確認。5000 以上はクラスタ化や WebGL の採否を検証し、合格を予断しない。

## 欠陥基準
S0: 本番外部決済起動、トークン漏えい、偽 Observed。S1: データ消失・異常ルートの誤成功。S2: Edge 誤拾取・Context 残留。S3: ラベルと余白。S0/S1 はリリース不可。
