# 用語集

| 日本語 | 中文 | English | 定義 |
|---|---|---|---|
| 要件定義 | 需求定义 | Requirements | 必要な機能・品質・制約の合意 |
| 基本設計 | 基本设计 | Basic Design | 外部仕様と全体構成の確定 |
| 詳細設計 | 详细设计 | Detailed Design | 各モジュール・型・遷移の仕様 |
| 試験設計 | 测试设计 | Test Design | 検証方法・入力・期待結果 |
| 因果分岐 | 因果分支 | Causal Branch | ガードに応じた次状態の差 |
| 正常系 | 正常Case | Happy Path | 全ガードを充足 |
| 異常系 | 异常Case | Failure Path | 条件失敗を安全に隔離 |
| 境界値 | 边界Case | Boundary | 上限・回復境界など |
| 複合障害 | 组合故障 | Compound Failure | 独立異常の同時注入 |
| 復旧/補償 | 恢复/补偿 | Recovery/Compensation | 外部副作用回避と再試行 |
| 証跡 | 证据 | Evidence | 主張の根拠への参照 |
| 未検証 | 未验证 | Unverified | 実行または証拠不足 |
| 仮説 | 假设 | Hypothetical | 事実と独立した構成提案 |
