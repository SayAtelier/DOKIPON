# Workflow 互換性・AI 制御インターフェース

## Canonical Contract
- `gemarc.workflow/v1`: semantics と presentation を分離。
- ID: WorkflowNode/Edge/Port に stable ID。
- Flow: Node Type, Guard, Input/Output Ports, Loop Policy, Retry/Timeout/Compensation, Evidence ID, Scenario ID。
- Agent Input: JSON Patch による操作提案、allowlist 操作、revision optimistic concurrency、dry-run、human approval。
- Agent Output: 変更対象 ID、構造差分、意味差分、失われた属性、検証結果、因果影響範囲。
- 未署名 Agent commands を直接実行しない。外部 AI/MCP transport は Designed、現コードは未提供。

## Format Adapter Gate（計画）
| 形式 | インポート計画 | エクスポート計画 | 無損失保証 |

`getArchitecture`, `querySubgraph`, `getCase`, `simulateCase`, `proposeWorkflowPatch`, `validatePatch`, `commitApprovedPatch`, `getEvidence`。読み取りと書き込みのスコープを区別し、人手承認なしで production updates しない。
