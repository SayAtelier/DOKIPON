# セキュリティ設計・脅威分析

| 脅威 | 影響 | 予防・検知 | 対象 Case |
|---|---|---|---|
| 仮説の事実昇格 | 不正確な設計・意思決定 | Evidence IDs / verification labels | EVIDENCE 002-007 |
| ワークフロー式の任意実行 | XSS/データ損傷 | Guard allowlist、eval 不使用 | WORKFLOW-RUN 003 |
| LINE access token 保存 | 個人情報漏えい | Bridge は true/false だけ返却 | LINE / SECURITY |
| 悪意ある JSON | メモリ・ロジック異常 | ID/port 検証、maxSteps | GRAPH / WORKFLOW / CAUSAL |
| IDOR / 権限逸脱 | 非許可設計文書参照 | サーバー側の RBAC/ABAC（未実装） | SECURITY 003 |
| ローカルストレージ競合 | 喪失・上書き | revision/checksum/atomic commit（設計） | PERSISTENCE / OFFLINE |
| LIFF login failed | ログインループ | External Browser Guest Safe Mode | LINE 002-006 |
| 結果の偽陰性 | 障害を成功と誤読 | failed/recovered/success を列挙し明確分離 | ALL |

## Privacy By Design
保存前に目的・本人同意、収集最小化、ログは匿名 Case ID、アクセストークン無記録、ユーザーデータ削除受付、保管期間は別途法令/運用決定。
