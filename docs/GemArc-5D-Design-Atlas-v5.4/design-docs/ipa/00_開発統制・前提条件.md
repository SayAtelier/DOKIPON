## 完了条件の分類
- *Implemented*: repository 内に実コードが存在し、本モデルのロジックを実装。
- *Verified*: 指定環境で実行したテストの証跡がある。
- *Designed*: 設計と契約は存在するが機能実装・検証は別途必要。
- *Hypothetical*: 事実と混同しない例示ケース。すべての Case はこの区分。
- *Unknown*: 証拠取得不可。
